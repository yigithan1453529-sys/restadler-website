# Promo images

- `thumbnail-1024.png` – static Poki thumbnail (square, full-bleed, no text; Poki needs at least 628 × 628).
- `thumbnail-animated-1080.mp4` – animated Poki thumbnail: 1080 × 1080, 50 fps, 5 s, no sound, no text.
  The van jumps a hill, picks up coins and stops in front of a cheering customer.
- `make-animated-thumbnail.cjs` – script that renders the video frames from the game's own drawing code.
