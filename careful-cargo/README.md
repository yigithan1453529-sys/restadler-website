# Careful Cargo

HTML5 game prototype for Poki (Vite + TypeScript + planck). See `docs/GDD.md` and `CLAUDE.md`.

```bash
npm install
npm run dev            # http://localhost:5173
npm run dev -- --host  # test on a phone in the same Wi-Fi
npm run build          # production build in dist/
npm run preview        # look at the build
```

Controls: → / D = drive, ← / A = brake / reverse (tilt in the air), R = restart, Esc / P = pause.
